# Seed Audio 音频创作插件 (@commerce/plugin-seed-audio)

轻作官方独立插件，基于火山引擎 **Seed Audio 1.0** 音频创作模型，支持多角色对话配音、有声书旁白、场景环境音效与背景音乐创作。

## 功能特性

- **多模态音频创作**：输入台词或场景声学描述，生成高自然度、带情感色彩的人声音频与环境音效。
- **声音参数控制**：支持 MP3 与 WAV 格式，支持 48,000 Hz 与 24,000 Hz 采样率，支持语速与音调精细调节。
- **凭据隔离**：火山方舟 API Key 安全保存在宿主凭据库，避免明文泄露。
- **离线安全**：基于轻作沙箱环境与受控网络通道，支持生成音频在线试听与本地保存。

## 开发与打包

```sh
npm install --ignore-scripts
npm test
npm run pack
```

打包生成的 `.ecplugin` 文件可在轻作桌面端的「插件管理」中直接导入使用。
